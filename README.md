# AIỎ - All-In-One Social

**AIỎ** là ứng dụng quản lý **đa nền tảng mạng xã hội** (All-In-One Social) chuyên nghiệp dành cho Windows — được xây dựng trên nhân Chromium siêu tốc và bảo mật. Quản lý **12 nền tảng** trong một cửa sổ duy nhất.

### Yêu cầu hệ thống

- [Node.js](https://nodejs.org/) phiên bản LTS (20.x trở lên)

### Chạy thử môi trường Dev

```bash
npm install
npm start
```

### Build phần mềm (.exe)

```bash
# Tạo file cài đặt (.exe)
npm run build
```

File thành phẩm sẽ xuất hiện trong thư mục `dist/`.
